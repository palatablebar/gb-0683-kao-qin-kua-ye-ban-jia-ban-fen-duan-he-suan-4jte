# 夜班反例

18位员工各有10月1日22点进、10月2日06点出。02点至03点休息，实际7小时，前两小时是假日3倍，次日5小时正常1倍，20元时薪合计220元。直接把整个夜班按归属日计假日会错算420元。脏批额外含缺时薪、冲突打卡、BOM、短行、空行与重复表头。

## 补卡与重算

缺 OUT 的班次不会被猜测补齐，整班先隔离。核算员提交显式补卡后重算：

```json
POST /api/runs/<run_id>/recalculate
{"parameters":{"corrections":[{"employee":"E001","shift_day":"2026-10-01","punch":"OUT","at":"2026-10-02T07:00:00+08:00","reason":"补离场"}]}}
```

原始打卡行与已存补卡记录不变，结果作为新修订生效；同一输入重复提交不会重复计入正常工时。

## 口径对比

同一批次可切换到 `pricing_basis=shift_day` 查看整班归属日口径（18 人合计 7560 元），再切回 `calendar_day`（3960 元）。两次结果各自成为一条修订，可按修订号导出；切换失败时页面与导出保留旧版并标注回退。

## 失败恢复

对账不平、封存校验未通过或参数非法时，重算返回 409/422，生效修订保持原样；指定不存在的修订导出时回落到当前生效版本，响应头 `X-Archive-Fallback: active`。
